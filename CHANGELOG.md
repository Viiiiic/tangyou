# Changelog

## [0.1.0.0] - 2026-04-30

### Added
- First H5 prototype for 糖友: elderly users can upload a meal photo and see large-text food recognition plus diabetes meal guidance.
- Local Node backend for MiniMax vision recognition and optional MiniMax TTS.
- GitHub Actions workflow for tests and GitHub Pages H5 deployment.

### Changed
- H5 frontend can connect to a separate backend with `?api=https://your-backend.example.com`.
